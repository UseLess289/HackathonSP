Architecture

Légère, modulaire, pensée pour la souveraineté.

Frontend Accessible
Interface Web Locale & ARIA

HTML5/CSS servi en local, Web Speech API (STT/TTS intégrés sans coût), gros contrastes, secours clavier à 100%.

Cœur & Sécurité
Machine à États & Contrat JSON

Validation stricte d'intention, liste blanche d'outils, séparation étanche entre données locales et requêtes IA.

Système Linux
GNOME Wayland & D-Bus

Intégration `anthony-mcp`, manipulation de LibreOffice Calc (`.ods` via `odfpy`), extraction locale `pdftotext`.
